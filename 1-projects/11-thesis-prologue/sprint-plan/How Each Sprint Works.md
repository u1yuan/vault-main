# How Each Sprint Works

← [[Thesis Sprint Curriculum]]

Every sprint uses the same two-week rhythm:

| Week | Focus |
| ---- | ----- |
| **Week 1** | Read "What to master" + resources from the map card; reproduce 2–3 minimal notebooks; write a 1-page concept note (definitions you could say in a defence). |
| **Week 2** | Build the project; freeze repo (`requirements.txt`, seeds, `config.yaml`); log ≥3 experiment runs; produce 2 publication-quality figures + short README. |

---

## Sprint exit criteria (all sprints)

> [!check] Definition of done
> - Public GitHub repo with tagged release `sprint-N`
> - Reproducible run: `python train.py --config configs/sprintN.yaml`
> - Written "defence sheet": 5 questions a panelist might ask + your answers
> - Figures at 300 DPI with axis labels and standalone captions
